## 📋 about

Fullstack implementation of **WebLarek** — an online store for developer merchandise. Includes frontend, backend, and full deployment setup via Docker and nginx.

<!-- ![demo](link-to-screenshot) -->

## 🛠️ tech stack

- **Frontend:** TypeScript + SCSS
- **Backend:** Node.js + Express + TypeScript
- **Reverse Proxy:** Nginx
- **Containerization:** Docker + Docker Compose
- **API Testing:** Postman collection included

## 🚀 getting started

```bash
git clone https://github.com/zeawale/web-larek-express.git
cd web-larek-express

docker compose up -d
```

App runs at `http://localhost`.

API collection: `WebLarek.postman_collection.json`
